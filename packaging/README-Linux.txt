KNID - Kirby: Nightmare in Dream Land, native for Linux

1. Make the AppImage executable: chmod +x KNID-*-x86_64.AppImage
2. Run it. Click "Choose ROM..." and pick your own dump of Kirby: Nightmare in Dream Land (USA).
   KNID checks the file and remembers where it is. It never copies or uploads it.
3. Settings (F1) > Game > Shortcut adds an applications-menu or Desktop entry that starts the
   game directly.

Settings, saves and save states are kept in:
  ~/.local/share/KNID/KNID/
