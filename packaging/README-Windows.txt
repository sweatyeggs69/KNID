KNID - Kirby: Nightmare in Dream Land, native for Windows

1. Unzip this folder anywhere (for example Documents\KNID).
2. Run KNID.exe. Windows SmartScreen may warn because the app is not code-signed yet:
   click "More info", then "Run anyway".
3. Click "Choose ROM..." and pick your own dump of Kirby: Nightmare in Dream Land (USA).
   KNID checks the file and remembers where it is. It never copies or uploads it.
4. Press Play. Settings (F1) > Game > Shortcut adds a Start menu or Desktop shortcut that
   starts the game directly.

Settings, saves and save states are kept in:
  %APPDATA%\KNID\KNID\
